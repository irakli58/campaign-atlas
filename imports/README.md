# Put your adventure here

Paste the PDF (or text or Markdown files) of an adventure you own into this folder, for example
`Curse of Strahd.pdf`. If you have it in parts, number them: `strahd-1.pdf`, `strahd-2.pdf` and so on.

Then, in the Atlas app, go to New campaign, then Import an adventure I own. Files in this folder are listed under
**From the imports folder**: pick yours, tick that it is your own copy, and press Import the adventure.

Nothing in this folder is ever committed or uploaded: Git ignores everything here except this note.
