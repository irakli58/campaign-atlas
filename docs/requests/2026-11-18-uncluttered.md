# Request, 18 Nov 2026: the UI uncluttered

After the UI overhaul's first pass, the user asked: "is the ui still cluttered or more readable and usable? that was
the main goal to fix". The answer: more readable in places, still cluttered (a heavy top on every page, about 110
buttons on screen, every button alike, overlays piled on the maps, a place's page mixing running the game with
editing it). The user, verbatim:

> work on it being uncluttered

The second pass, proposed and taken up:
1. the top of the page down to one line; the "New" banner and the tracker only when they matter;
2. each view one plain main action, the rest quieter;
3. a place's page: running the game first, editing behind an Edit switch;
4. the overlays on the maps gathered.
