# The bible

The finished, playable story, one file per chapter, each finished before the next is begun:

- `01-truth-and-timeline.md`: what really happened, dated; the antagonists' plan and its clock
- `02-cast.md`: every principal in full, minor figures in a line each
- `03-clue-web.md`: every conclusion, its three clues or more, where each lies, the hint if it is missed, where it leads
- `04-places.md`: every location, its tier, what happens there, who is there, what it holds
- `05-acts.md`: the story scene by scene
- `06-endings.md`: at least three, and what each one takes
- `07-handouts.md`: what the players will hold

As long as the story deserves. See `references/council.md` in the campaign-atlas skill.
